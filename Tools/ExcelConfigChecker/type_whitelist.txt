# Excel 配置 Type 合法性列表
#
# 本文件用于检查以下配置表的 Type 列是否合法：
#   UnitData.Type   -> 运行时通过 Units.<Type> 反射创建单位类
#   SkillData.Type  -> 运行时通过 Skills.<Type> 反射创建技能类
#   BuffData.Type   -> 运行时通过 Buffs.<Type> 反射创建 Buff 类
#   ModifyData.Type -> 运行时通过 Modifys.<Type> 反射创建修饰器类
#   BulletData.Type -> 运行时通过 Bullets.<Type> 反射创建弹道类
#
# 格式说明：
#   [UnitData] 等方括号行表示分区，只识别上面 5 个表名；
#   分区内每行写一个合法 Type（区分大小写，前后不要加空格）；
#   # 或 ; 开头的行是注释，可以随意增删；
#   删除一行 = 禁止该 Type；新增一行 = 允许新子类。
#
# 维护方式：
#   1. 新增 Unit/Skill/Buff/Modify/Bullet 子类后，在对应分区补一行类名；
#   2. 删除或废弃子类后，删除对应行，再运行检查即可找出仍在使用的旧 Type；
#   3. 也可以点击工具的“扫描合法 Excel 更新配置...”，
#      选择一个确认可用的 Excel，工具会把其中出现的全部 Type 自动合并进来。
#
# 特殊值：
#   SkillData 的 Type = Json 表示 JsonSkill（不是 Skills.Json 类），已在下方保留。
###############################################################################
