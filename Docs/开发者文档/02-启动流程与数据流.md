# 02 启动流程与数据流

## 1. 启动流程

以主场景 `SampleScene.unity` 为入口：

1. `Init.Awake()`：保存单例、`DontDestroyOnLoad`、注册未观察任务异常日志。
2. `Init.Start()`（async）：
   - `Addressables.InitializeAsync()` 初始化 Addressables；
   - `await Database.Instance.Init()` 加载全部配置；
   - `GameData.Instance.Init()` 读取存档并初始化编队；
   - `AudioManager` 播放主界面 BGM；
   - `UIManager.Instance.ChangeView<MainUI.UI_Main>(MainUI.UI_Main.URL)` 打开主界面。
3. `UIManager.Awake()` 早于 `Init.Start()` 执行：绑定全部 FairyGUI 扩展（`Binder.BindAll()`），并通过 Addressables 同步加载 `BattleUI/MainUI/SkillIcon/Res/DungeonUI/MapBuilderUI/DIY` 等 UI 包。

## 2. 配置数据流

### 2.1 源数据：Excel

- 玩家数据表位于根目录 `Excel/`（`Main/`、`Test/`、`一方通行/`、`尊尼获加/`、`Diy优胜/`）。
- 每张 Sheet 的名字对应一个配置类，如 `UnitData`、`SkillData`、`BuffData`。
- 约定：
  - 第 1 行：字段中文名/说明；
  - 第 2 行：字段名（与 `Assets/Scripts/Config/*.cs` 的属性名一致）；
  - 第 3 行：字段类型（`int/float/string/bool/枚举/配置表名/Vector2/...`）；
  - 第 4 行起：数据行；首列为 Id（`#` 开头表示注释行，跳过）。

### 2.2 导表：Excel → JSON 行文本

- 编辑器菜单 **Tools → 导出配置**（`Assets/Editor/ExcelEditor/ExcelExportEditor.cs`）扫描 `./Excel/Main`：
  - `ExportClass()` 根据 Sheet 自动生成/覆盖 `Assets/Scripts/Config/<SheetName>.cs`；
  - `ExportData()` 把每行数据转换为 JSON 对象，写出到 `Assets/Bundles/Data/<SheetName>.txt`（每行一个 JSON）。
- 游戏内也可以在 `MainUI` 主界面勾选 Excel 后点击导出，走 `ExcelHelper.Export(ExcelList)`，由玩家自定义表（DIY）生成运行时数据。
- 类型转换规则见 `ExcelHelper.Convert`：
  - `int/float/double` 原样输出；
  - `string` 加引号；
  - `枚举` 转 int；
  - 引用其他表的类型（如 `UnitData`、`SkillData[]`）转换为该表 Id 的**数组下标**（索引）；
  - `Vector2/Vector2Int/Vector3/Rect` 转成 JSON 对象；
  - `Vector2[]` 用 `#` 分隔点、`,` 分隔分量；
  - `string[]` 用 `,` 分隔，失败时用换行分隔。

### 2.3 运行时加载：Database

`Assets/Scripts/Database.cs` 是全局配置单例：

- 内部结构：`Dictionary<Type, IConfig[]>`，**数组下标即配置 Id 索引**。
- 编辑器下 `Database.Init1()` 同步读取 `Assets/Bundles/Data/<name>.txt`；运行时 `Init()` 优先读热更路径 `StreamingAssets/Data/<name>.txt`，失败则走 Addressables。
- 常用 API：
  - `Get<T>(int id)` / `Get<T>(string id)` / `Get<T>(Func<T,bool>)`；
  - `GetAll<T>()`；
  - `GetIndex<T>(string id)` / `GetIndex<T>(T config)`；
  - `TryGet...` 系列安全版本。
- 特殊处理：`SkillData.Type == "全局技能"` 的条目会被加入 `Database.globalSkills`，每个单位 `Unit.Init()` 时追加学习。
- `Database.Maps` 缓存地图；`GetMap(package, name)` 先查缓存，再读 `Assets/Bundles/Data/Map/<package>/<name>.map`。

### 2.4 配置类

`Assets/Scripts/Config/*.cs` 中的类均实现 `IConfig`（`Id` 属性）。常用的：

| 类 | 说明 |
|---|---|
| `UnitData` | 单位静态数据（基础属性、Type、模型/动画、技能列表、主技能、职业、可部署格子类型等） |
| `SkillData` | 技能数据（Type、SP 类型、伤害倍率、攻击范围、Modifys、Data 扩展字典等） |
| `BuffData` | 状态数据（Type、持续、升级、依赖、生效条件等） |
| `BulletData` | 弹道数据 |
| `ModifyData` | 修饰器数据 |
| `CardData` | 编队卡片（`units` 数组指向 UnitData 下标） |
| `ContractData` | 危机合约词条 |
| `SpineData` | Spine 资源索引 |
| `DungeonLevelData` / `RelicData` / `EventData` / `RewardData` | 肉鸽相关 |

## 3. 存档数据流

- 存档文件：`StreamingAssets/data.sav`（编辑器下 `Assets/StreamingAssets/data.sav`，被 .gitignore 忽略）。
- `GameData.Instance.Init()`：
  1. `SaveHelper.LoadFile("/data.sav")` 读 JSON；
  2. `JsonHelper.FromJson<GameData>` 反序列化；
  3. `LoadTeamDataFromSave()` 将存档编队中的卡牌替换为当前卡池中同 `UnitId` 的实例（防止卡池变动导致空引用）；
  4. `LoadCardDataFromExcel()` 根据 `CardData` 表补全缺失卡牌；
  5. 校验 `ExcelList`（玩家自定义 Excel 路径列表）。
- `SaveHelper.SaveData()`：把 `GameData` 序列化并写回 `data.sav`。
- 存档类 `Client/GameData.cs` 持有 `Cards`、`Teams[4]`、`Name`、`Bgm`、`showHP/showElement`、`ExcelList` 等。

## 4. 进入战斗的数据流

1. 主界面选择地图 → `BattleInput` 结构：
   ```csharp
   class BattleInput {
       string MapName; string MapPackage; int Seed; List<int> Contracts;
       Team Team;        // 普通模式编队
       Dungeon Dungeon;  // 肉鸽模式
       bool IsPreview; MapInfo MapInfo;
   }
   ```
2. `BattleManager.StartBattle(BattleInput)`：
   - 打开加载界面 → 存档 → 读取 `MapInfo`；
   - 若地图未绑定场景（`Scene` 为空），加挂 `MapBuilder` 场景并用 `MapManager.Build(GridInfos)` 动态生成地块；
   - 否则加载地图绑定场景；
   - 创建 `Battle` 并 `Battle.Init(battleConfig)`；
   - `ResHelper.Prepare` 预加载编队、波次、场景单位资源；
   - 打开 `BattleUI.UI_Battle`，进入战斗。
3. `BattleManager.Update()` 以固定步长 `SystemConfig.DeltaTime`（1/60 秒）追帧调用 `Battle.Update()`，实现确定性模拟。

## 5. 热更路径

`PathHelper` 统一管理路径：

- `AppResPath` = `Application.streamingAssetsPath`
- `AppHotfixResPath`：移动平台为 `persistentDataPath/<productName>/`，否则同 `AppResPath`
- 资源读取优先热更目录，失败回退 StreamingAssets/Addressables。
