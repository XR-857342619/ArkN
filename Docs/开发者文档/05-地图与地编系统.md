# 05 地图与地编系统

## 1. 地图数据结构

核心类在 `Assets/Scripts/MapBuild/MapInfo.cs`：

```csharp
class MapInfo {
    string MapName; string Description; string Scene;
    Vector3 CameraPos;
    int InitHp; int InitCost; int MaxBuildCount; int MaxCost;
    List<string> Contracts;
    GridInfo[,] GridInfos;               // 二维网格（可为 null 时表示使用绑定场景中的网格）
    List<UnitInfo> UnitInfos;            // 场景单位
    List<PathInfo> PathInfos;            // 寻路路径
    List<WaveInfo> WaveInfos;            // 波次
    List<OverwriteUnitInfo> UnitOvDatas; // 单位数值覆盖
    bool NoBuildLimit;
    int BoxCount;                        // 箱子数
}
```

- `GridInfo`：`X/Y/CanBuildUnit/FarAttack/CanMove`。
- `UnitInfo`：`UnitId/X/Y/Tag/ActiveTime/Direction/LifeTime`（Tag 波次触发）。
- `WaveInfo`：`UnitId` 或 `sUnitId`（敌人字符串 Id）、`Delay/GapTime/Count`、`Path`（路径名）、`CheckPoint`（检查点波次）、`Tag`（波次标签）、`UnAppear`。
- `PathInfo`：`Name/FlyPath/Path(List<PathPoint>)/length`。
- `OverwriteUnitInfo`：按 `UnitId` 覆盖 `Atk/Hp/Def/MagDef/Speed/Agi`。

## 2. 地图文件

- 存储位置：`Assets/Bundles/Data/Map/<地图包名>/<地图名>.map`（JSON），以及 `<包名>/config.ini`（包配置）。
- `Database.GetMap(packageName, mapName)` 负责读取与缓存，缓存键为 `package:map`。
- 编辑器下 `SaveHelper.Save(str, packageName, fileName)` 会写入 `Assets/Bundles/Data/Map/<package>/<fileName>.txt`（注意：编辑器下扩展名是 `.txt`，真机上是 `.map`，见 `SaveHelper.Save` / `ExistFile` 的条件编译）。
- 内置地图包：
  - `Bundles/Data/Map/Main/`（12 个文件：地图 + config）
  - `Bundles/Data/Map/test02/`（1 个文件）
  - 运行时的 `StreamingAssets/Map/Main/`（真机可写目录）

## 3. 地图场景与动态建图

地图可以有两种模式：

1. **绑定场景**：`MapInfo.Scene` 非空，如 `Maps/TestMap.unity`；场景中已摆好 `MapGrid` 子物体，`MapManager.Awake()` 自动收集 `Grids`。
2. **动态生成**：`MapInfo.Scene` 为空，`BattleManager.StartBattle` 加载 `MapBuilder` 场景，调用 `MapManager.Build(mapInfo.GridInfos)` 按 `GridInfo` 程序化生成 `MapGrid`。

## 4. MapManager 与 MapGrid

`Assets/Scripts/MapBuild/MapManager.cs`：

- `Grids` 二维数组；`Awake()` 收集子物体 `MapGrid`。
- `SelectGrid()`：异步等待玩家点击地块。
- `Brush(Action<MapGrid>)` / `EndBrush()`：刷子模式，用于地编器批量编辑。
- `ShowPath(List<PathPoint>, bool fly)`：调用 `AStarPathFinder.FindPath` 在地编器显示路径。
- `AutoBuild()`：根据 `S_playground` 子物体位置/贴图自动设置 `MapGrid`。

`MapGrid`（`Assets/Scripts/MapBuild/MapGrid.cs`）是地块 MonoBehaviour，字段 `X/Y/CanBuildUnit/CanMove/FarAttackGrid`，并可自动生成子 Sprite。

## 5. 寻路

- 主要实现：`Assets/Scripts/Core/Map/PathFinder_AStar.cs`（自写 `AStarPathFinder`）。
  - `FindPath(Tile[,] map, ...)` / `FindPath(MapGrid[,] map, List<Vector3> points, bool fly)`。
  - 支持平滑拐角（`cornerSmoothDistance`、`segmentsPerCorner`）、视线检测、`ITileData` 通行性。
- `Tile`（`Core/Map/Tile.cs`）实现 `ITileData`，是战斗中的地图格。
- 工程内还有 AstarPathfindingProject 插件（`AstarPathfindingProject.csproj`），但目前大部分调用已被自写 A* 替代（代码中仍保留注释掉的 A* 调用）。

## 6. 地编器

- 场景：`Assets/Scenes/MapBuilder.unity`。
- UI：`Assets/Scripts/UI/MapBuilder/` 与 `AutoRelease/MapBuilderUI/`。
- 主要界面：
  - `UI_MapBuilder`：总入口；
  - `UI_MapInfo` / `UI_MidInfo` / `UI_MidPage`：地图与地块信息；
  - `UI_PathPage` / `UI_PathInfo` / `UI_PathPoint`：路径编辑；
  - `UI_WavePage` / `UI_WaveInfo`：波次编辑；
  - `UI_EnemyInfo`：敌人配置；
  - `UI_Preview`：地图预览。
- 地图保存：`SaveHelper.Save(json, packageName, fileName)` → `Assets/Bundles/Data/Map/<package>/<fileName>.txt`（编辑器下）。
- 地图包配置：`SaveHelper.SavePackageConfig(packageName, config)` → `config.ini`。
- 攻击范围编辑器：`Tools/攻击范围编辑器.exe`（外部工具，用于生成技能攻击范围数据）。

## 7. 战斗中的地图

- `Battle.Map`（`Core/Map/Map.cs`）是战斗地图容器，初始化时从 `MapInfo.GridInfos` 创建 `Tile[,]`。
- `Tile` 持有 `Units`（占用单位，排序用于阻挡）与 `MidUnits`（空中/不可阻挡单位）。
- `Battle.UnitMap` 是敌人快速检索的哈希集合二维数组，每帧重建，用于索敌查询。
- 敌人沿 `PathInfo` 行进：`OneWave` 按时间触发，`敌人` 单位读取路径点逐点移动，到达终点扣减关卡生命。

## 8. 地图开发注意

- 地图 JSON 中的敌人推荐用 `sUnitId`（字符串 Id，如 `enemy_1106_byokai`），避免使用旧的 `UnitId` 下标。
- 保存地图后编辑器下会 `AssetDatabase.Refresh()`。
- `StreamingAssets` 被 gitignore，真机可写地图应放热更目录；开发时地图源文件在 `Assets/Bundles/Data/Map/` 下。
- 预览模式：`BattleInput.IsPreview` 与 `MapInfo` 允许不进入完整战斗，只在地编器里预览波次和路径。
