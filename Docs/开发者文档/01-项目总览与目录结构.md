# 01 项目总览与目录结构

## 1. 项目背景

- 本项目是 ArknightR（独钓寒江翎 开发的明日方舟同人模拟器）的 **N 版分支**。
- 原项目停止开发后，糖浆继续维护两年并于 2025/1 停止；本分支由 **X2r(None)** 与 **HJsama** 继续开发。
- 玩法：还原《明日方舟》的核心战斗（部署干员、费用回复、阻挡、技能、状态、弹道），并额外支持**玩家地图编辑器（地编）**、**DIY 单位编辑**与部分肉鸽（Dungeon）玩法。
- 仓库根目录见 `README.md`。

## 2. 技术栈

| 项目 | 版本/来源 | 说明 |
|---|---|---|
| Unity | 2021.2.10f1 | `ProjectSettings/ProjectVersion.txt` |
| 脚本 | C# | 无 asmdef，全部在 Assembly-CSharp 中编译 |
| UI | FairyGUI（Assets/Plugins/FairyGUI） | UI 包从 `Assets/Bundles/UI/*_fui` 经 Addressables 加载 |
| 骨骼动画 | Spine Runtime 3.8（Assets/Plugins/Spine） | 单位/敌人/召唤物表现 |
| 寻路 | 自带 A*（`Assets/Scripts/Core/Map/PathFinder_AStar.cs`）+ AstarPathfindingProject（工程内，部分已不启用） | 主要使用自写的 `AStarPathFinder` |
| 资源加载 | Unity Addressables 1.19.15 | `Assets/AddressableAssetsData` |
| 配置读取 | ExcelDataReader + EPPlus（读/写 .xlsx） | `Assets/Plugins/ExcelDataReader`、`EPPlus.dll` |
| 表达式/脚本 | Microsoft.CodeAnalysis.CSharp.Scripting（Roslyn） | `UnifiedExpressionEngine` 动态编译表达式 |
| JSON | Newtonsoft.Json（Plugins 内置） | `JsonHelper` |
| Tween | DOTween | `Assets/Plugins/DOTween.dll` |
| 拼音 | Pinyin 插件 | 中文排序等 |
| 其他 DLL | System.Windows.Forms、SharpZipLib、System.Linq.Dynamic.Core | 编辑工具/打包 |

## 3. 顶层目录

```
zhou-master/
├── Assets/
│   ├── AddressableAssetsData/  Addressables 配置
│   ├── Bundles/                运行时资源（UI/Units/Effect/Data/Image/Audio...）
│   ├── Editor/                 编辑器脚本（导表、打包、Spine 导入、FairyGUI）
│   ├── Plugins/                第三方插件（FairyGUI/Spine/Newtonsoft/Excel...）
│   ├── Res/                    源资源（Spine 骨骼、头像、技能图标、Shader...）
│   ├── Scenes/                 场景（SampleScene/Default/MapBuilder/Maps/...）
│   ├── Scripts/                游戏代码（414 个 C# 文件）
│   └── StreamingAssets/        运行期可写/可读数据（被 .gitignore 忽略）
├── Excel/                      玩家 Excel 数据（Main/Test/一方通行/尊尼获加/DIY优胜）
├── Docs/                       文档
├── Docx/                       设计文档
├── Tools/                      地编工具（攻击范围编辑器.exe 等）
├── UIProject/                  FairyGUI 工程源文件（Z 项目）
├── ProjectSettings/            Unity 工程设置
└── Packages/                   Unity 包清单
```

> `.gitignore` 忽略了 `Library/`、`Temp/`、`obj/`、`Logs/`、`Assets/StreamingAssets/` 等生成目录。克隆后需要用 Unity 打开重新生成 Library。

## 5. 资源目录（Assets/Bundles）

| 目录 | 内容 |
|---|---|
| `Bundles/UI/` | FairyGUI 包二进制（`*_fui`）与图集 |
| `Bundles/Units/` | 单位预制体（2348 个文件，干员/敌人/召唤物） |
| `Bundles/Effect/` | 特效预制体（414 个文件） |
| `Bundles/Data/` | 导表产物 `*.txt`（每行一个 JSON）与地图数据 |
| `Bundles/Data/Map/<package>/` | 地图包（`*.map` 地图 JSON、`config.ini`） |
| `Bundles/Image/` | 背景、立绘（StandPic）、头像 |
| `Bundles/Audio/` | 背景音乐 |
| `Bundles/Other/` | 地编用网格、线条、球等 |
| `Bundles/DungeonTile/` | 肉鸽地图块预制体 |

## 6. 场景

Build Settings 中的场景（`ProjectSettings/EditorBuildSettings.asset`）：

- `Assets/Scenes/SampleScene.unity` —— 主入口，挂载 `Init`、`UIManager` 等全局对象
- `Assets/Scenes/Default.unity`
- `Assets/Scenes/Maps/TestMap.unity`、`H6-4.unity`、`Rune_01-03.unity`、`Map1.unity`
- `Assets/Scenes/MapBuilder.unity` —— 地编器场景

其他开发场景：`BoneFollowTest`、`Dungeon`、`PathTest`、`Tool`，以及 `Scenes/Maps/Rogue/` 下的肉鸽地图模板。

## 7. 关键第三方目录

- `Assets/Plugins/FairyGUI/Scripts/`：FairyGUI 运行时代码
- `Assets/Plugins/Spine/`：Spine 运行时与编辑器
- `Assets/Plugins/Newtonsoft.Json/`：JSON.NET
- `Assets/Plugins/ExcelDataReader/` + `EPPlus.dll` + `Excel.dll`：Excel 读写
- `Assets/Plugins/CurvedLine/`：曲线绘制（部分脚本原为 UTF-16，已转 UTF-8）
- `Assets/Plugins/Pinyin/`：中文拼音排序
