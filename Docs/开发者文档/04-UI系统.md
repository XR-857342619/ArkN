# 04 UI 系统

## 1. 框架

- UI 基于 **FairyGUI**。UI 包源文件在 `UIProject/Z/`（FairyGUI 编辑器工程），导出产物为 `Assets/Bundles/UI/*_fui` 与图集。
- 运行时通过 **Addressables** 加载 `_fui` 包（`UIManager.LoadPackge`），用 `UIPackage.AddPackage` 注册。
- `Assets/Bundles/UI/` 目前有 35 个文件，包包括：`BattleUI`、`MainUI`、`SkillIcon`、`Res`、`DungeonUI`、`MapBuilderUI`、`DIY`。
- `UIManager` 是全局单例，挂载在主场景 `SampleScene` 的 `Init` 物体上，`Awake()` 时绑定并加载所有 UI 包。

## 2. 目录结构

```
Assets/Scripts/UI/
├── UIManager.cs     包加载、View 切换（ChangeView/GetView）
├── TipManager.cs    全局飘字提示
├── IGameUIView.cs   界面进入回调接口（Enter）
├── AutoRelease/     FairyGUI 自动生成的 partial 类（UI_*.cs + *Binder.cs）——不要手改
│   ├── BattleUI/  MainUI/  DungeonUI/  MapBuilderUI/  DIY/
├── Main/            手写 partial 逻辑（与 AutoRelease/MainUI 同名类）
│   ├── Battle/  UnitInfo/  ...
├── Battle/          战斗界面手写 partial 逻辑
├── Dungeon/         肉鸽界面手写 partial 逻辑
│   ├── Dialogue/  Recruit/

├── DIY/             DIY 编辑器界面手写 partial 逻辑
└── Healper/         IconHelper、ExtextureLoader
```

## 3. 代码生成与 partial 约定

FairyGUI 导出工具会为每个 UI 组件生成：

- `UI_<组件名>.cs`：`public partial class UI_Xxx : GComponent`，包含：
  - 成员变量（控件引用）；
  - `public const string URL = "ui://<包ID>/<组件ID>"`；
  - `CreateInstance()`；
  - `ConstructFromXML(XML xml)` 中 `GetChildAt` 绑定控件并调用 `Init()`；
  - `partial void Init();`
- `<包名>Binder.cs`：在 `BindAll()` 里把 URL 绑定到类。

**手写逻辑**放在 `Assets/Scripts/UI/<模块>/UI_Xxx.cs`，用 `partial class UI_Xxx` 实现 `Init()` 和业务逻辑。

示例：

```csharp
// AutoRelease/MainUI/UI_Main.cs（生成）
namespace MainUI {
    public partial class UI_Main : GComponent {
        public GButton m_battle;
        public const string URL = "ui://k4mja8t1kbte0";
        public override void ConstructFromXML(XML xml) { ...; Init(); }
        partial void Init();
    }
}

// Main/UI_Main.cs（手写）
namespace MainUI {
    partial class UI_Main : IGameUIView {
        partial void Init() {
            m_battle.onClick.Add(() => { ... });
        }
        public void Enter() { ... } // IGameUIView 可选
    }
}
```

> 修改 UI 请使用 FairyGUI 编辑器改 `UIProject/Z`，重新导出后让工具重新生成 `AutoRelease` 类；**不要直接改 AutoRelease 下的文件**。

## 4. 界面切换

```csharp
var view = UIManager.Instance.ChangeView<MainUI.UI_Main>(MainUI.UI_Main.URL);
```

- `ChangeView<T>(url)`：先从缓存取；没有则 `UIPackage.CreateObjectFromURL(url)` 创建、适配屏幕（SetSize + AddRelation）、加入 `GRoot.inst`，隐藏上一个界面，并在实现 `IGameUIView` 时调用 `Enter()`。
- 常用模式：
  ```csharp
  var ui = UIManager.Instance.ChangeView<UI_Team>(UI_Team.URL);
  await ui.ChooseTeam();
  UIManager.Instance.ChangeView<GComponent>(URL); // 返回本界面
  ```

## 5. UI 包加载与资源回调

`UIManager.LoadPackge(PackageName)` 流程：

1. Addressables 同步加载 `Assets/Bundles/UI/<PackageName>_fui`；
2. `UIPackage.AddPackage(bytes, PackageName, load)` 注册包；
3. `load` 回调按需通过 Addressables 加载包内图集/图片资源（`Assets/Bundles/UI/<name>`）。

## 6. 主要界面与入口

| 界面 | URL 类 | 职责 |
|---|---|---|
| 主界面 | `MainUI.UI_Main` | 设置、队伍、战斗入口、导出 Excel、DIY 入口、肉鸽入口 |
| 编队 | `MainUI.UI_Team` / `UI_TeamSelect` / `UI_TeamUnit` | 4 个编队槽位、选人、技能选择 |
| 战斗 | `BattleUI.UI_Battle` 等 27 个 | 费用条、血条、技能按钮、伤害数字、暂停/投降、结算 |
| 地编 | `MapBuilderUI.UI_MapBuilder` 等 16 个 | 网格、路径、波次、敌人、合约、保存/预览 |
| 肉鸽 | `DungeonUI.*` 18 个 | 队伍、招募、奖励、剧情对话 |
| DIY | `DIY.UI_Main` | 自定义单位/技能/属性编辑 |
| 战斗子界面 | `Main.Battle` / `Battle` 等 | 部分旧版本界面 |

## 7. UI 开发注意

- 命名约定：FairyGUI 控件导出成员名带 `m_` 前缀（如 `m_battle`、`m_Name`）。
- 热更新 UI 资源时，`Addressables.LoadAssetAsync<TextAsset>(..._fui)` 使用 `WaitForCompletion()` 同步阻塞；UI 包在启动时一次性加载。
- `TipManager.Instance.ShowTip(msg)` 是全局飘字，可在战斗/编辑器逻辑中直接调用。
- 部分 UI 存在新旧两套（如 `UI/Battle` 与 `UI/Main/Battle`），开发新功能请以 `AutoRelease` 生成的 URL 类为主。
