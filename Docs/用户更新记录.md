## v1.6.5（2026-08-28）

### 数据与设置
- 重构游戏数据加载逻辑：
  - 运行时优先加载热更目录 `Data/<表名>/<Excel文件名>.txt`，并按 `Data/<表名>/_index.txt` 生成与旧版一致的 Id 索引。
  - 热更目录数据缺失时，自动回退到内置 `Data/<表名>.txt` / Addressables。
  - 启动时先读存档中的 Excel 选择列表，再计算“排除列表”，避免加载未启用的玩家 Excel 数据。
- 玩家 Excel 导出改为并行按文件写入、统一生成 `_index.txt`，并增强路径过滤/去重，修复多次点击导表设置后的显示错误。

## v1.3.18

### 新增内容
- 新增 **再部署策略**：
  - **默认**：部署后待部署区进入冷却，冷却结束前不可部署。
  - **唯一**：场上存在同 ID 干员时，待部署区不可部署；该单位离场后才开始冷却。
  - **队列**：每个单位独立计算冷却，待部署区只要有任一单位可用即可部署。
- 新增 **可部署上限** 配置字段，用于控制部分单位的部署数量。

### 工具改进
- 新增 **Excel 列同步工具**：
  - 可选择基准 Excel 与指定 Sheet，将目标 Excel 的列结构同步为与基准一致。
  - 同步前自动备份，降低误改风险。

### 其他
- 更新了战斗配置数据（干员/技能/Buff/子弹等）。
- 同步更新了多份玩家 Excel 表格。
