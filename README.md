# 项目说明
本项目为ArknightR[zhou-master](目前明日方舟传播最广的ArknightR模拟器)的一个分支[N版].
ArknightR项目最初由 **独钓寒江翎** 独立开发, **整合运动_w** 在后续加入并承担了部分美术素材导入的工作,因各种原因独钓寒江翎停止了项目的开发,GitHub代码仓库也被删除/隐藏.
随后从GitHub仓库中获取了完整工程文件的 **糖浆** 开始进行后续开发,但未选择创建新的代码仓库重新开源工程文件.持续更新2年后也在不久前(2025/1)停止了更新.

# 原项目说明
 _使用"互联网获得素材"的自制明日方舟，总体还原度已经较高了，支持玩家地编功能。
可破坏障碍物寻路还没做，多加个寻路Layer应该就行了。
索敌那一块效率比较低，而且现在逻辑比较乱，找个时间重写一下。
持续施法类技能基本全靠trick...不过既然实现了暂时不想改了。_
